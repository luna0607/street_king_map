预填好的 GitHub issue 表单已在新标签页中打开。请在该页面点击 "Submit new issue" 以完成提交 — 需要 GitHub 账号。

提交后，机器人大约需要 1–2 分钟 来运行、开启 Pull Request 并将 PR 链接回复在 issue 下。您可以在 Actions 标签页 观察进度。

您的编辑仍保存在此浏览器中，因此如果出现意外，您不会丢失这些更改。在维护者合并 PR 后，这些点位将出现在公开地图上，您本地的“新”标记将自动清除。
